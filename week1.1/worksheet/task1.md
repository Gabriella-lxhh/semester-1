# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists everything in the current folder|
|     cd directory_name       | moves into a named folder|
|     cd ..                   | moves up one directory level|
|     cd -                    | moves to the previous directory|
|     mkdir directory_name    | makes a new named directory|
|     touch filename          | makes a new file|
|     git status              | shows the current status of the Git repository|
|     git add -A              | stages all changes, -A is an option which means all|
|     git commit -m ""        | bundles these changes into one 'commit', -m is an option and lets you set a commit message|
|     git push                | sends these changes back to the remote Github server|
|     git pull                | downloads and merges latest updates from the remote Github repository to local files|
